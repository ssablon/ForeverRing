# Forever Mouse Ring-Range (Multi language)

**Created by Vohnka** — https://wow-forever.fr

Cursor ring for **WoW Forever Classic** (camelot client, interface 16001). A second circle shows range. Cast progress fills the ring. The interface is translated in **11 languages** (English fallback). **This addon never casts.**

## What you see

- Gold (or class-color) ring on the mouse
- Range circle inside the cursor ring, yard numbers above
- Cast progress on the ring — red if interrupted
- Auto language follows the game client; pick another language in options, including French

## Range

Auto uses mouseover, then focus, then target. You can lock it to one unit. The ring hides over menus so it does not cover bags or the spellbook.

## Install

1. Close the game client.
2. Copy the ForeverRing folder into `World of Warcraft\_classic_beta_\Interface\AddOns\`
3. Restart → Addons → enable **Forever Mouse Ring-Range (Multi language)**.

The CurseForge app often installs into official Classic. On Forever, unzip by hand into `_classic_beta_`.

## Commands

`/fring` or `/foreverring`

- `/fring options` — settings
- `/fring toggle` — show or hide

Minimap button: left-click = options, right-click = show or hide. Drag to move.
