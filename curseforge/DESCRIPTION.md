# Forever Mouse Ring-Range

**Multi language** · Created by **Vohnka** · [wow-forever.fr](https://wow-forever.fr)

A ring on the mouse for **Forever Classic** (camelot, interface 16001). A second circle shows range. Cast progress fills the ring.

**This addon never casts.**

---

## Features

- Gold ring, or your class color, or any color you pick
- Range circle **inside** the cursor ring, yard numbers **above**
- Cast progress on the ring — turns **red** if the cast is interrupted
- Auto language follows the game client (11 languages, English fallback)
- Pick another language in options, including French
- Hide the ring over menus, bags, and the spellbook
- Minimap button: left-click options, right-click show or hide

## Range

**Auto** checks mouseover, then focus, then target. You can lock it to one unit. Optional filters: hostile only, hide dead.

## Install

1. Close the game client.
2. Copy the `ForeverRing` folder into `World of Warcraft\_classic_beta_\Interface\AddOns\`
3. Restart → Addons → enable **Forever Mouse Ring-Range (Multi language)**.

The CurseForge app often installs into official Classic. On Forever, unzip by hand into `_classic_beta_`.

## Commands

`/fring` · `/foreverring`

- `/fring options` — settings
- `/fring toggle` — show or hide
