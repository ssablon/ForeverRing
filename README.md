# Forever Ring

Cursor ring for **WoW Forever** Classic. A second circle around the mouse shows target range. It never casts.

The interface follows the game client language (11 languages, English fallback).

Slash: `/fring` · `/foreverring` · `/fring options`

Author: Vohnka — https://wow-forever.fr

This build is a work in progress. It is not on CurseForge yet.
