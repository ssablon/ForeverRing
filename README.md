# Forever Mouse Ring-Range

Cursor ring for **WoW Forever** Classic. A second circle around the mouse shows range. It never casts.

**Development status:** Active development by Vohnka has **stopped**. The project is **open source** ([MIT](LICENSE)). Source and forks: [github.com/ssablon/ForeverRing](https://github.com/ssablon/ForeverRing). Anyone may continue improving it.

Range uses mouseover, then focus, then target (or pick one in options). The ring hides over menus. Cast progress turns red if interrupted.

Player texts are English by default. Auto follows the game client language. In options, Language can switch to any of the 11 supported languages (including French). Missing strings fall back to English.

Slash: `/fring` · `/foreverring` · `/fring options` · `/fring toggle`

Author: Vohnka — https://wow-forever.fr

Download: [CurseForge](https://www.curseforge.com/wow/addons/forever-mouse-ring-range)
